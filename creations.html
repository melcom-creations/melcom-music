# melcom's FFmpeg Audio Normalizer v4.1.2 (Herbstklang Edition)

Herbstklang Edition

melcom's FFmpeg Audio Normalizer is a free Windows application for loudness normalization based on EBU R128, LUFS and True Peak processing. Powered by FFmpeg, it supports WAV, MP3, FLAC, M4A, OGG and other common audio formats for individual files and complete batches.

The Herbstklang Edition adds batch analysis reports, optional verification of encoded output, and a workspace you can resize to suit your workflow. Separate analysis and normalization result windows offer clipboard reports and CSV export. Its new herbstklang theme brings warm brown backgrounds, amber accents and cream-colored text.

The application is available in English, German, Polish and Swedish, with dedicated help files for every included language. Questions or issues? Contact me.

Note: The complete FFmpeg suite is required. Download it from this page and select the folder containing ffmpeg.exe, ffplay.exe and ffprobe.exe in the program's Options.

What's new in v4.1.2 (Herbstklang Edition)?

  • Batch Analysis Results for loudness, True Peak, LRA, PLR and signal details, with comparisons against your selected targets
  • Output Verification and Results with optional measurements of finished files and comparisons of original, target and output values
  • Reports and CSV Export for analysis and normalization, with individual or complete clipboard reports and result windows that open automatically after completed runs
  • Encoder Headroom from 0 to 3 dB for MP3, M4A and OGG to allow for peaks introduced during lossy encoding
  • Adjustable Workspace with draggable dividers, saved window size and layout, a corner resize grip and a reset action
  • Clear Encoding Defaults: 320 kbps CBR for MP3 and M4A, 320 kbps ABR for OGG, and explicit VBR quality presets
  • PLR Statistics alongside the existing loudness and signal measurements
  • Remembered Folders for audio files and album artwork across application restarts
  • Metadata and Artwork Repairs, including MP3 URL compatibility with XMPlay, tag preservation and M4A cover handling
  • herbstklang Theme with warm autumn colors, selected by default when no theme has been saved

Herbstklang Edition helps you inspect your original audio, review the finished output and arrange your workspace, with practical improvements to normalization, metadata and artwork handling.

For a full list of changes, see the included CHANGELOG.md.

# melcom's GhostKey Sentinel v1.1

melcom's GhostKey Sentinel is a free, lightweight AutoHotkey script designed to fix mechanical keyboard chattering-the frustrating issue where a single key press registers multiple times.

The script runs quietly in the background and filters unwanted repeated key events without adding noticeable input lag. It is intended for keyboards that have begun registering duplicate presses.

Note: Requires the free AutoHotkey v2 software to be installed on your system.

What's new in v1.1?

  • Bug Fix: Fixed a conflict with the Steam Overlay. The script now ignores the Tab key to ensure the Shift + Tab shortcut works reliably in all applications and games.

Key Features

  • Solves frustrating double-typing issues (key chattering).
  • Runs silently in the background with minimal resource usage.
  • Adds no noticeable input lag to your typing.
  • Easy "set it and forget it" installation.
  • Fully open-source and customizable.

# Highlighter with X - Tampermonkey Script (v1.3.0)

Highlighter with X is a compact userscript that lets you highlight any text on any webpage in yellow, green, or red, and remove the highlight instantly with a hover-activated "×" button.

It's perfect for marking up patch notes, articles, or forum posts. The script also automatically saves your highlights and restores them when you revisit the page.

  • Custom colors for green & red
  • Black text for maximum readability in dark mode
  • Hover-X with white border and larger click area
  • Keyboard shortcuts: ALT+1/ALT+2/ALT+3 to highlight, ALT+0 to remove
  • Auto-saves highlights and restores them later

Requires the free Tampermonkey browser extension to run.
