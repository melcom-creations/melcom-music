Music trackers

Classic, modern, chip-based, and platform-specific ways to make tracked music.

  • Adlib Tracker II - FM tracker for OPL3 chips (AdLib/SB)
  • AmigaKlang - Tool for generating Amiga-style synth sounds
  • BeRoTracker - Modular Windows tracker with VST support
  • ChibiTracker - Cross-platform Impulse Tracker clone
  • DefleMask - Chiptune Tracker - Multi-system tracker for classic sound chips
  • enotracker - Tracker for Atari POKEY sound
  • FamiTracker - NES/Famicom music tracker with expansion chip support
  • Fasttracker II clone - Modern clone of the DOS classic FastTracker II
  • Game Boy Tracker - Tracker for creating music on Game Boy/Color
  • GoatTracker 2 - C64 SID music tracker for Windows/Linux
  • Hivelytracker - AHX/HVL tracker with up to 16 channels
  • MadTracker - Windows tracker with VST and ReWire support
  • MilkyTracker - Open-source FastTracker II-style tracker
  • OpenMPT 💙 Pick - Advanced Windows tracker with many module formats
  • PreTracker - This is a crossdev 'chipmusic' tracker (running on Windows) NEW
  • ProTracker 2 clone - Portable clone of Amiga ProTracker 2.3D
  • Schism Tracker 💙 Pick - Open-source Impulse Tracker reimplementation
  • SID Factory II - Cross-platform editor for C64 SID music
  • SID-Wizard - Feature-rich C64 SID tracker with MIDI support
  • Skale Tracker - FT2-style tracker with VST and SoundFont support
  • TIATracker - Tracker for Atari 2600 (VCS) music
  • Trackerboy - Game Boy music tracker with custom engine
  • TrackMeister 💙 Pick - Fullscreen MOD/XM/IT player for compos
  • VGM Music Maker - Tracker for Sega Genesis/Master System/Game Gear
